Building NETRA: an AI accessibility assistant

NETRA is an accessibility application I'm building to help visually impaired users interact with their smartphones and navigate real-world environments independently — combining voice-driven app control with real-time computer vision for obstacle detection.

The core idea is to close the gap between two separate problems that visually impaired users face every day: operating a touchscreen-first phone, and moving safely through physical space. NETRA tackles both with the same voice-first interaction model.

Project goal

Build an intelligent accessibility app that lets users control their phone and navigate their surroundings independently using voice commands and on-device computer vision, without relying on complex gestures or constant visual attention.

Voice-based app navigation

  • Control smartphone apps using voice commands
  • Convert speech input into structured intents
  • Automate multi-step tasks — sending messages, opening apps, making payments
  • Provide contextual guidance based on the current screen

Real-world navigation assistance

  • Detect obstacles using the device camera in real time
  • Identify obstacle direction — left, right, or center
  • Estimate approximate distance to nearby objects
  • Provide voice alerts to guide users safely

Intelligent interaction system

  • An intent recognition system to understand user commands
  • A task orchestration engine for executing multi-step actions
  • Contextual suggestions based on ongoing user activity

Performance, reliability & safety

  • Low-latency real-time processing for both voice and vision
  • Battery-conscious design for continuous, all-day operation
  • Offline support for critical safety features
  • Priority-based alerts that avoid excessive or repetitive notifications

Tech stack

Built natively for Android in Kotlin, using CameraX for real-time camera access, Android's SpeechRecognizer and TTS engines for voice I/O, Retrofit/OkHttp for networking, and Room for local storage.

This is very much a work in progress — I'll keep updating this log as the intent-recognition and obstacle-detection pipelines mature. The repo has the latest code and commit history.
